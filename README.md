# 🎬 YouTube Highlight Clipper (YouTube切り抜き自動ジェネレーター)

YouTube動画から音声エネルギー・リアクション（叫び声・大きな笑い・急な音量上昇）を自動解析し、盛り上がりシーンの候補抽出および高品質な切り抜き動画（16:9 MP4）をピンポイントかつ高速に生成するツールです。

---

## ✨ 主な機能

- **🔥 音響エネルギー盛り上がり自動解析**:
  - `librosa` によるRMSエネルギー・ダイナミックレンジ解析。
  - 実況者のリアクションやジャンプスケア、ハイライトシーンをスコアリングして自動検出。
- **⚡ 超高速ピンポイント切り抜き（DASHセグメント直接取得）**:
  - 動画全体（数GB）をダウンロードすることなく、指定区間のみを数秒でダウンロード＆FFmpeg精密トリミング。
- **🖥️ 直感的な Web UI**:
  - YouTube埋め込みプレイヤーでのシーンプレビュー。
  - 盛り上がり候補一覧からのワンクリック切り抜き生成。
  - 自由な時間指定（`mm:ss` または秒数）による手動切り抜き。
  - 任意のYouTube動画URLを入力して新規解析・切り抜き。
- **💻 CLI（コマンドライン）対応**:
  - スクリプト単体での直接実行・バッチ処理にも対応。

## 🚀 セットアップ

### 1. 必要環境
- Python 3.10 以上
- （FFmpeg は `imageio-ffmpeg` パッケージ経由で自動構成されます）

### 2. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

---

## 📖 使い方

### 1. Web UI で使う（おすすめ）

Webサーバーを起動します：
```bash
python server.py
```

ブラウザで以下のURLを開きます：
👉 **http://127.0.0.1:8080**

- 画面上部の **URL入力欄** にYouTubeのURLを入力して「新規動画解析」をクリックすると、動画の自動解析が始まります。
- 検出された盛り上がり候補の「再生」でプレビュー、「切り抜く」で即座にMP4が生成されます。

---

### 2. コマンドライン（CLI）で使う

#### ① 指定した時間範囲を直接切り抜く場合
```bash
# 書式: python segment_clipper.py <開始秒> <終了秒> "<出力ファイル名.mp4>"
# 例: 1分30秒 (90秒) 〜 2分15秒 (135秒) を切り抜き
python segment_clipper.py 90 135 "clip_sample.mp4"
```

#### ② 音響解析のみを実行してハイライト一覧を取得する場合
```bash
python analyze_audio.py
```
（実行後、`highlights.json` に上位ハイライトのタイムスタンプとスコアが出力されます）

## 📁 ディレクトリ構成

```text
youtube_clipper/
├── analyze_audio.py      # 音声抽出＆盛り上がりシーン自動解析スクリプト
├── segment_clipper.py    # DASHセグメント高速ピンポイント切り抜きエンジン
├── server.py             # Flask Web API サーバー
├── index.html            # Web UI フロントエンド
├── requirements.txt      # 依存ライブラリ一覧
├── clips/                # 生成された切り抜き動画（MP4）の保存フォルダ
└── README.md             # プロジェクト説明書
```
